# 第二轮：原生多预测块 DHF

本轮对齐报告 §3.1 的共享历史、多预测块训练机制。训练增强、分类协变量角色采样和官方大规模预训练配方不属于本轮范围。

## 测试结果

全部 18 个适配器、40 个模型／预测长度组合、80 个验证／测试评分已完成。独立数值审计通过 560 项主要指标标量复算；输入来源、权重、预测、监督计数和汇总表均已核验。

主要观察：

- 200 步 DHF 相对 200 步单窗口，ETTh1 的 WQL21 在 96／192 步预测上分别降低 0.2745%／0.9075%；ETTh2 分别降低 0.1443%／0.1280%。这些是冻结配置下的四组描述性结果，不构成显著性或普遍优越性的结论。
- MASE 并非所有条件都改善：ETTh2 的 96 步预测高出单窗口约 0.0510%。DHF 相对原模型的 WQL21 改善约 0.20%–0.71%。
- 概率区间存在取舍：ETTh1 的 192 步预测，覆盖率由单窗口 82.075% 变为 DHF 80.746%，更接近名义 80%；ETTh2 同长度则由 77.108% 变为 73.829%，欠覆盖更明显。不能仅凭 WQL21 宣称不确定性校准更好。
- 单窗口全部选择第 200 步；ETTh1 的 DHF 和 92 步对照均选择第 50 步；ETTh2 的 DHF 选择第 200／200／100 步，92 步对照全部选择第 92 步。
- 因此，92 步对照仅匹配**完成作业的近似监督预算**。ETTh1 选中 DHF 权重只累计看到 2,329,600 个监督点，低于单窗口选中权重的 4,300,800 点；它不是选中权重间的等监督量实验。不同学习率日程、上下文和预测距离分布仍是混杂因素。

同样 200 步，DHF 训练循环耗时约为单窗口的 1.63 倍，监督点为 2.17 倍；这不能替代与“逐块独立重算”实现的同任务对照，也不能直接验证官方训练加速幅度。28 对 14 的每目标输入 token slots 包含 DHF 未监督的首个解码位置；它只是几何计数，不是 FLOPs。

18 个作业训练循环累计 794.915 秒。预检为单窗口／DHF 各 10 步 7.141／4.868 秒，包含不同预热状态与初始化，不能据此比较策略速度；加 40% 余量后的完整矩阵预估为 39.90 分钟。从首个训练作业启动到最后一次测试预测记录约 14 分 28 秒，初始数据准备、协议冻结及之后的独立数值审计另计。

补充上下文曝光审计见 [exposure_audit.json](exposure_audit.json)：12 个 DHF 作业重放布局后与最终布局 RNG 状态一致；六组成对主实验的窗口采样器状态及窗口候选集合一致。DHF 实现的历史范围为 32–416 点，按预测块计数的平均历史约 198.0–201.4 点；单窗口固定为 256。该审计同时区分完整训练曝光和选中检查点曝光。

## 对照设计

- Timestral-5M，固定官方 revision `bdd20cfc15a3fea0e4cb5ccef37f8d3ca7aa335f`。
- ETTh1、ETTh2 全部 7 个目标；8640/2880/2880 顺序切分；只用训练段拟合各目标的均值和总体标准差。
- 两个主对照均采用归一化空间损失、LoRA rank 8/alpha 16、学习率 `1e-4`、batch 4×累积 4、seed 42/43/44。
- 单窗口训练输入历史 256、监督未来 192；DHF 使用相同抽样的完整 448 点序列，从首个 32 点上下文后监督剩余 416 点。DHF 预测块长度独立均匀采样 1–6 个 patch，末块截短；所有目标共享每个样本的划分。此分布是项目选择，不是官方公开配方。
- DHF 使用独立且可恢复的布局随机数发生器，窗口索引采样器不受布局抽样影响；在本轮完整观测的 ETT 数据上，两个主对照使用相同的窗口索引序列。
- 公共选优准则始终为普通单起点、历史尺度损失，预测长度与步长 192，每次验证 15 个不重叠区间；布局随机数不在验证中消耗。
- 测试评估固定历史 256，分别预测 96、192，步长等于预测长度，每个分区分别有 30、15 个区间。每个预测起点可使用此前已观测到的真实值。
- 所有适配器完成训练并冻结权重校验值后，才开始任何 held-out 测试预测；不利用测试成绩追加搜索。

**相同优化步数并不等于相同工作量。** DHF 每步有效监督点约为单窗口的 416/192 倍，预测起点、历史长度与预测距离分布也不同。报告的 token slot 数只描述两路输入的几何大小，不能代替 FLOPs 或实测速度。

额外的近似完整作业监督预算对照已在预检确定预算允许后启用，DHF 步数固定为 `floor(main_steps*192/416)`。200 步主实验对应 92 步 DHF，监督量约为单窗口的 99.67%。它仍有不同的优化步数和学习率日程，不能单独识别共享编码的因果效果。

## 指标与证据

WQL21 以全部目标、预测位置与区间的标签绝对值总和归一化，CRPS9 近似仅使用 0.1–0.9 的九个分位数。MAE/MSE 和 80% 区间宽度使用训练段标准化单位；MASE24 使用完整训练段的 24 小时季节差分分母。均值和样本标准差反映三个种子的差异，不表示统计显著性。

正式结果、冻结配置与校验值由脚本生成：`protocol.json`、`selected_models.json`、逐次结果、`runs.csv`、`summary.csv`、`integrity_audit.json`。完整模型、检查点、预测数组与执行源码快照在忽略目录 `runs/report-round2/`。独立审计重新校验预测标签和七项主要指标，并检查汇总表及实际监督计数。

训练耗时来自训练循环内部，包含验证和检查点写入，不包含数据集构造、初始加载及最终导出；预检 wall time 则包含该次调用的初始化，不能用来比较策略速度。内存记录包括每 100 毫秒抽样的 MPS live/driver allocator 最大值，可能遗漏短时峰值；RSS 是同一实验进程累计的高水位，不能作为每个模型的独立峰值或增量内存比较。

## 复现

仓库内的结果是冻结历史记录。重新训练请使用新的输出与结果目录；以下示例的两条训练命令使用相同目录，核验命令也指向该次新实验：

```sh
python scripts/run_report_round2.py --phase preflight --supplementary --output runs/my-dhf-comparison --results results/my-dhf-comparison
python scripts/run_report_round2.py --phase run --supplementary --output runs/my-dhf-comparison --results results/my-dhf-comparison
python scripts/audit_report_round2.py --output runs/my-dhf-comparison --results results/my-dhf-comparison
python scripts/analyze_report_round2_exposure.py --output runs/my-dhf-comparison --results results/my-dhf-comparison
```

本地仍保留本轮完整 `runs/report-round2/` 产物时，可直接运行不带目录参数的两个审计命令核验本文结果。

8 小时属于实验规划预算，脚本不强制在该时刻终止，最终以实际耗时为准。每个策略先运行 10 个优化步，只按耗时选择 200/100/50 的公共预算，然后在测试前冻结是否加入近似监督量对照。中断后保留原始输出目录，使用相同命令恢复。源码或配置改变时必须使用新输出和结果目录；原始提交号在相同冻结源码的恢复运行中保持不变。

本实验属于短期适配，不能视为官方预训练复现；ETT 是否被官方预训练使用未知；稀疏起点评估不能与 stride 1 榜单直接比较。新增机制保持可选，预测效果退化也如实保留。
