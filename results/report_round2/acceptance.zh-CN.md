# 第二轮验收：原生共享历史 DHF

状态：**本地验收通过，等待用户审核后再提交和推送。** 核心实现、独立审查、正式实验、博客终审及交付边界检查均已完成。机器可读证据见 [acceptance.json](acceptance.json)。

## 实现范围

- `training_strategy="dhf"` 复用官方网络，在一次 Transformer 前向内共享因果上下文，为多个独立预测块产生监督。
- 初始前缀、最大块长可配；均匀块长与末尾截断属于项目配方，不能视为官方未公开的采样分布。
- 每个块仅读取起点之前的真实目标／历史协变量及块内因果预测；未来已知数值协变量遵循官方角色隔离。
- 每块从自己的历史统计起步，再以预测中位数推进归一化；真实未来不进入统计。
- 支持全参数、LoRA、数值协变量、缺失标签、非整 patch 尾部、精确恢复、合并权重与适配器导出。
- 默认窗口训练与分类协变量行为保持兼容。DHF 分类协变量、缺失增强、动态角色采样及官方预训练复现不在本轮范围。

## 独立检查

实现 agent 之外的只读审查未发现阻塞问题。主 agent 额外验证多块共享计算与逐块独立前缀计算的损失及所有参数梯度一致，并检查未来目标／历史协变量的输入梯度为零、未来已知协变量保留可用路径。

CPU 与 MPS 上覆盖随机／常数／缺失输入、全参数／LoRA、有限梯度及参数更新、带 dropout 的精确恢复和导出重载。真实 Timestral-5M 权重另行核对 CPU/MPS 的逐块预测、归一化统计与反向传播。CUDA 因本机无设备而跳过；本轮不能扩展声称四档权重与全部硬件已验证。

正式对照采用两个数据集、三种子、200 步主预算和 92 步补充预算。DHF 对单窗口的测试 WQL21 变化如下（均值之比，负数表示误差下降）：

## 实验解释边界

主比较固定归一化损失和普通 H192 历史尺度验证准则，使用三种子、两个 ETT 数据集和两个测试预测长度。相同 448 点样本中，窗口监督 192 点／变量，DHF 监督 416 点／变量；后者历史与距离分布也不同。92 步补充对照仅近似匹配 200 步窗口的完整作业标签量，不一定匹配验证选中权重的累计监督；优化步数、日程和计算仍不等，不能识别共享编码单一机制的因果效应。

完整协议、权重及数据校验、预测留档、实际监督和成本统计见 [实验记录](README.md)。8 小时为规划预算，脚本没有强制截止。三个种子的样本标准差不代表置信区间或显著性。
