# 第六轮：上下文表征的分类与模拟异常探测

本轮交付可独立使用的 `encode()`，并观察冻结预测主干的几何是否能支持简单下游任务。
这是独立社区项目的有限探索。官方 [Timestral 报告§5](https://arxiv.org/pdf/2610.37585)
仅把分类和异常检测列为后续方向；没有官方下游实验可供复现。

**结果：两种池化在 GunPoint 均未胜过原始序列 1-NN；模拟异常上，六项统计基线的整体 AP/F1 更高。**
表征检测的低误报同时伴随高漏报，不能只报告零误报。

## 固定设置与数据

- 发布的 Timestral-5M，revision `bdd20cfc15a3fea0e4cb5ccef37f8d3ca7aa335f`，FP32 CPU、4线程、batch16，无训练，无权重选优。不是前几轮微调优胜模型。
- [GunPoint 官方描述](https://www.timeseriesclassification.com/description.php?Dataset=GunPoint)确认50训练、150测试、长度150、两个类别。官方zip下载返回403，使用固定 [aeon镜像提交](https://github.com/aeon-toolkit/aeon/tree/98c13323251a011722de2d6f68a772554af9b9ea/aeon/datasets/data/GunPoint)，保留原始归档值，不再标准化。原始序列、mean、last均使用Euclidean 1-NN，相等距离取最早训练索引。所有池化预先指定，测试标签只计分。
- ETTh2沿用 [ETDataset固定源](https://github.com/zhouhaoyi/ETDataset/blob/1d16c8f4f943005d613b5bc962e9eeb06058cf07/ETT-small/ETTh2.csv)及[文件清单](data_manifest.json)。使用OT列、训练`[0,8640)`、校准`[8640,11520)`、测试`[11520,14400)`，完整源CSV保留。窗口96、stride24，无窗口跨切分，357/117/117窗；训练点均值与标准差用于两方法输入缩放。
- 每个种子42/43/44在117测试窗中均匀选35窗，尖峰12、水平偏移12、卡死11；同一批注入供两个检测器。起点均匀取整数`[24,72)`；尖峰为单点±6倍训练原始标准差，偏移为24点±3倍，卡死为24点重复紧邻前值。独立扰动各重叠窗口，不构造连续故障时间线。
- mean表征不做外部特征标准化。统计基线取均值、总体标准差、最小值、最大值、平均绝对一阶差分、最大绝对一阶差分，每维只用训练窗均值/标准差缩放（尺度下限1e-12）。两方法均为到完整357训练窗bank的最近Euclidean距离。
- 阈值只用117个未注入校准窗分数的99%分位数，NumPy `method="linear"`；分数**严格大于**阈值才报异常。阈值表征2.0352041865、统计1.1327872321，所有种子共用。没有测试标签调参、point adjustment或事后选池化。

所有源码、测试、示例、审计器、上游源码、权重、配置和数据身份先写入[冻结协议](protocol.json)。
首次计算结束后环境回执因uv环境无pip而失败，尚未输出/查阅指标；保留失败尝试全部数组与源码快照，
改用`importlib.metadata`记录包清单，补充验收数组审计后重新冻结并全量重跑。协议的`amendment`记录旧协议哈希；
实验方法/参数未改变。最终协议SHA256为`9d675cecebac10ab8ce772d0b354eed9779bac79afbd6a0c893318ec2144fe9d`。

## API边界与验收

`encode` 返回逐patch/逐变量最终上下文隐藏层、观测有效掩码、mean/last池化、原输入patch坐标。
只支持数值目标；角色/协变量不支持时明确拒绝；微调模型有协变量配置时须显式选择target-only。
全缺失变量为零并标记无效，部分patch保留有效观测；mean对有效patch等权，不按点数加权。
因果性以patch末端为界，整窗表征读取全窗，不能冒充在线逐点检测。

[真实5M验收](acceptance.json)：CPU/MPS提取结果与官方forecast上下文hidden hook的最大绝对差均为0；
调用前后forecast和state_dict逐位不变，两设备最大绝对差4.9472e-6。输出形状`(2,3,5,192)`，全部有限；
mask/pooling/裁剪/变长batch隔离/patch因果/角色拒绝/导出字节不变有机制测试。
本轮没有重做28M/123M/209M的表征矩阵，也没有CUDA实机证据。

完整测试`251 passed, 50 skipped`；跳过为环境/集成条件，见本地`runs/report-round6/pytest.log`。
独立[audit回执](audit.json)核对完整source/array集合与哈希，从保留输入重新构造注入、统计量、1-NN、
校准阈值、全部分类/整体/分类型/种子聚合指标，并核验CPU/MPS数组有限性和跨设备差异。
同一auditor已从冻结源码快照实际执行成功，不依赖runner指标函数。
额外独立复核改变batch16→7与threads4→2，重新计算全部1025条输入的表征，均与保存数组逐位一致；
记录在本地`runs/report-round6-root-acceptance/neural-recomputation.json`。
